# Ujjwal Jain — Portfolio Website

This is a lightweight, beginner-friendly portfolio website built with **HTML, CSS, JavaScript, and Three.js**. It has no React project, package manager, build step, backend, database, or environment variables.

## Files

| File | Purpose |
|---|---|
| `index.html` | The page content: navigation, sections, cards, links, and placeholders. |
| `styles.css` | The responsive layout, typography, colors, hover effects, and CSS animation. |
| `script.js` | The mobile menu, scroll reveals, and animated Three.js particle background. |

## Run locally

Open `index.html` in a browser. For the most consistent behavior, use a simple local server such as the VS Code **Live Server** extension.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload these files to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. GitHub will provide your public URL after deployment.

## Customise before publishing

Replace every `PLACEHOLDER_*` value in `index.html` with your own projects, skills, location, résumé URL, and repository links. You can adjust the blue palette in `styles.css`, especially the variables near the top of the file.

## External resources

The website loads Google Fonts and Three.js from public CDNs. An internet connection is therefore needed for the custom fonts and animated 3D background. The rest of the page remains ordinary HTML, CSS, and JavaScript.
